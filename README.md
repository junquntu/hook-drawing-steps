# 吊钩 · 尺规作图分步图解

按《机械制图》习题 **1-12 抄画平面图形大作业（续）作业2：吊钩** 的图样，
把整张图拆成 **12 个可复现的尺规作图步骤**，每一步都给出：

* 画什么（本步操作）
* 圆心在哪里、距基准线多少、半径多少（尺寸线与尺寸界线）
* 用什么线（粗实线 / 细实线 / 细点画线 / 作图辅助线）
* 圆规怎么用（针尖插哪个圆心、张开多少、从哪个切点划到哪个切点）

---

## 一、尺寸与线段分析

### 1. 定形尺寸（决定形状大小）

| 尺寸 | 含义 |
|---|---|
| φ23、38 | 钩柄外径与长度 |
| C2 | 顶部 45° 倒角，倒角宽度 2 |
| φ30 | 肩部直径 |
| R3.5 | 颈部根部圆角 |
| φ40 | 喉部内圆（**母圆**） |
| R48 | 钩背圆弧（**母圆**） |
| R60、R40 | 钩颈过渡的两段圆弧 |
| R40（内） | 钩孔内侧圆弧 |
| R23 | 钩尖背面圆弧 |
| R4 | 钩尖圆角 |

### 2. 定位尺寸（决定圆心位置）

| 尺寸 | 含义 |
|---|---|
| 38 | 顶面 → 肩部 |
| 90 | 肩部 → 水平基准线 |
| 9 | 竖直基准线 → O₁（R48 圆心） |
| 15 | 水平基准线 → C₁（R40 内圆心）所在横线 |

### 3. 线段分类（决定作图顺序）

| 类别 | 图线 | 缺几个条件 |
|---|---|---|
| **已知线段** | φ23×38 钩柄、φ30 肩部、C2、φ40 圆、R48 弧 | 0（尺寸齐全，直接画） |
| **中间线段** | R40（内）、R23 | 1（圆心在某条基准线上） |
| **连接线段** | R60、R40（上）、R4、R3.5 | 2（只给半径，靠两个相切条件） |

> 作图顺序固定为：**基准线 → 已知线段 → 中间线段 → 连接线段**。
> 顺序错了，后面每一条弧都要回头改。

## 二、几何解算（圆心坐标，单位 mm，原点 O 为两基准线交点）

```
O   = (0, 0)          φ40 圆心（喉部）
O1  = (9, 0)          R48 圆心
C1  = (-58.09, -15)   R40(内) 圆心   ← |C1| = 40+20 = 60，且 y = -15
C2  = (-62, 0)        R23 圆心       ← |C2-O1| = 48+23 = 71，且在水平基准线上
C3  = (45, 66.14)     R60 圆心       ← x = -15+60，|C3| = 60+20 = 80
C4  = (55, 75.02)     R40(上) 圆心   ← x = 15+40，|C4-O1| = 48+40 = 88
C5  = (-40.6, 16.5)   R4 圆心        ← |C5-C2| = 23+4 = 27，|C5-C1| = 40-4 = 36
```

相切点：

```
R48–R40(上) (34.09, 40.92)     R48–R23 (-39, 0)
R23–R4      (-43.77, 14.02)    R4–R40(内) (-38.66, 19.96)
R40(内)–φ40 (-19.37, -5.00)    φ40–R60 (11.25, 16.54)
R60–直线x=-15 (-15, 66.14)     R40(上)–直线x=15 (15, 75.02)
```

**求圆心的三条口诀**

1. 与直线相切 → 作平行线，距离 = R；
2. 与圆外切 → 辅助圆半径 = R₁ + R₂；
3. 与圆内切 → 辅助圆半径 = R₁ − R₂。

## 四、线型规范（GB/T 4457.4）

| 线型 | 用途 | 线宽 |
|---|---|---|
| 粗实线 | 可见轮廓线 | 0.5~0.7 |
| 细实线 | 尺寸线、尺寸界线、引出线、作图辅助线 | ≈ 粗线 1/3 |
| 细点画线 | 中心线、对称线 | ≈ 粗线 1/3 |
| 细虚线 | 不可见轮廓线（本图无） | ≈ 粗线 1/3 |

* 中心线两端应超出轮廓 **3~5 mm**，不能画满整张图；
* 尺寸界线由轮廓、轴线或中心线引出，超出尺寸线约 2 mm；
* 尺寸线必须与所注线段平行，不能与其他图线相交；
* 半径尺寸线通过（或指向）圆心，只画一个箭头；直径尺寸线穿过圆心，两端画箭头。
